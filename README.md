# Experimental Design and Data Analysis Projects Overview

This repository contains projects and assignments from the **Experimental Design and Data Analysis (EDDA)** course, primarily implemented in R. The work includes hypothesis testing, statistical modeling, and data visualization techniques applied to real-world datasets.

---

## Assignments

### **Assignment 0: Introduction to R**
- **Objective**: Get familiar with R and RStudio, including basic data manipulation, plotting, and statistical functions.
- **Outcome**: Gained foundational skills in R programming, such as working with vectors, matrices, and plots.

### **Assignment 1: Statistical Analysis of Birthweights and Cholesterol**
- **Key Topics**:
  - Hypothesis testing (t-tests, sign tests, Wilcoxon tests)
  - Confidence intervals (standard, bootstrap, and asymptotic methods)
  - Power analysis and paired data analysis
- **Outcome**:
  - Investigated birthweight data for statistical significance in mean and variance.
  - Explored cholesterol level changes using paired tests and linear models.

### **Assignment 2: ANOVA and Regression Modeling**
- **Key Topics**:
  - ANOVA and linear regression analysis
  - Interaction effects and transformations
  - Step-up modeling and multicollinearity analysis
- **Outcome**:
  - Modeled tree volumes and criminal expenditure with explanatory variables.
  - Optimized regression models with step-up and LASSO techniques.

---
